# Have an agent adopt COD for a UI boundary

Use the supplied `cod-adopt` skill with one concrete request in your existing application. The [shared-button application](../native-stack/README.md) is a runnable reference, not an agent-generated efficacy result.

For example: “Make this action use the new rounded appearance and preserve loading, disabled and keyboard behavior.” The agent should inspect the existing component's supported API, extend a reusable variant when appropriate, register the actual consuming screens, and add qualified checks.

Ask the agent to run the native behavior/build checks, observe a shared provider change through the real screens, and qualify correct independent copies plus unused-owner decoys. Contract edits and component/screen edits require explicit review reconciliation. Protect the checks and acceptance records through your delivery process.

See [installation](../../docs/agent-setup.md), [the workflow skill](../../skills/cod-workflow/SKILL.md), and [the adoption walkthrough](../../docs/agent-demonstration.md). Research records are stored outside Git and are not part of ordinary adoption.

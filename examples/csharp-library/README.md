# A price with one owner

Checkout asks Pricing for an order total. Pricing applies a discount. Checkout must not keep its own copy of that formula.

Open [capability.json](capability.json), then [Pricing](src/Pricing.cs), [Checkout](src/Checkout.cs), and [the native checks](checks/Program.cs). They use the same contract format and toolkit as the JavaScript and Vue examples.

From the repository root, after building the toolkit and installing the .NET 10 SDK:

```sh
node dist/cli.js inspect examples/csharp-library capability.json
node dist/cli.js verify examples/csharp-library capability.json --allow-execution
```

The check first runs a real app that calls Checkout and prints its result. It then changes Pricing from a 10% discount to a 20% discount and rebuilds the app. The expected total changes from 90 to 80 for a subtotal of 100.

The wrapper follows the new total. The copy and the caller that discards Pricing's answer still return 90. They must pass today's behavior and fail ownership. A compiler or process failure is an unresolved observation, not evidence that a copy was caught.

The `changes` mode also changes only the expected total, then only the owner, and requires the same behavior assertion to reject each disagreement. All temporary source edits are restored.

For an intentional edit, reconcile the contract, code and counterexamples, then run:

```sh
node dist/cli.js review examples/csharp-library capability.json --reason "Describe the reviewed pricing change and callers"
node dist/cli.js verify examples/csharp-library capability.json --allow-execution
```

`capability.review.json` is generated by the toolkit. Do not edit its hashes or have CI refresh it. `pnpm verify:pr` runs this example through the same CLI, with no bypass for the C# profile.
